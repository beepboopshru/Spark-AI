# ⚡ Spark AI | Startup Idea Generator

Stop staring at a blank screen. Generate your next million-dollar app idea in seconds using high-reasoning AI models.

![Spark AI Preview](https://your-vercel-url.com/preview.png)

## 🚀 Features
- **AI-Powered Ideation:** Leverages OpenRouter's 2026 Free Tier (Gemini 3 Flash & GPT-OSS).
- **Glassmorphism UI:** A sleek, modern "Restaurant Pink" aesthetic built with Tailwind CSS.
- **Failover System:** Automatically cycles through multiple AI models if one is rate-limited.
- **Copy-to-Clipboard:** Save your favorite ideas instantly.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, FontAwesome.
- **Backend:** Node.js, Express.js.
- **AI Engine:** OpenRouter API (Accessing Gemini, Llama, and Mistral).
- **Deployment:** Vercel (Serverless Functions).
